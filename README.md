# To-Do List

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript. It helps users organize and manage their daily tasks efficiently.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive and user-friendly interface
- Simple and clean design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
To-Do-List/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
